# 💰 Personal Finance Dashboard

> Interactive financial analytics application for tracking income, expenses, savings and spending patterns.

## 🌐 Live Demo

👉 https://personal-finance-dashboard-ankit.streamlit.app/

## 📌 Overview

The Personal Finance Dashboard converts financial records into interactive visual insights.

It helps users understand:

* Income
* Expenses
* Savings
* Spending patterns
* Financial KPIs
* Category-wise spending

## ✨ Features

* 💵 Income tracking
* 💳 Expense analysis
* 💰 Savings calculation
* 📊 Interactive charts
* 📈 Financial KPIs
* 🔎 Spending pattern analysis
* 📅 Period-based analysis

## 🧰 Tech Stack

* Python
* Streamlit
* Pandas
* Plotly

## 🔄 Workflow

```text
Financial Data
      ↓
Data Cleaning
      ↓
Categorization
      ↓
KPI Calculation
      ↓
Visualization
      ↓
Financial Insights
```

## 🚀 Run Locally

```bash
git clone https://github.com/ankitkumaranalytics/personal-finance-dashboard.git

cd personal-finance-dashboard

pip install -r requirements.txt

streamlit run app.py
```
